# Brain index

This brain is organized with PARA. Five folders, every page lives in exactly one:

- [inbox](inbox/index.md) - new, unfiled. Empty it when you touch it.
- [projects](projects/index.md) - active work with an end state.
- [areas](areas/index.md) - ongoing responsibilities with no end date.
- [resources](resources/index.md) - reference material worth keeping.
- [archive](archive/index.md) - finished projects and dead topics. Nothing gets deleted, it gets archived.

Page rules (OKF):
- One concept per page.
- Frontmatter on every page, with at least `type:` (note, decision, reference, index, log).
- Every folder has an `index.md` listing its contents. Keep it current.
- Link related pages by name instead of repeating content.
- Plain, specific page names a human can find.
