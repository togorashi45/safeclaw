# Default ninja cadence (edit per client)
D1 social touch -> D2 text -> D4 call (call sheet) -> D6 email ->
D9 direct mail -> D12 client call/door-knock reminder -> pulse every 14d.

Message patterns: short, specific, references something true about THEM
(their property, their post, their listing). Never open with "I hope this
finds you well." Never mention automation. One ask per message. The door-knock
reminder includes: dossier link, best time window, and the one-line opener.
