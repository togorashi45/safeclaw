# Calendar Optimizer

## Overview
Optimize your calendar using time-blocking principles for RE investors. Structures your week around revenue-generating activities first (lead gen, acquisition calls, closings), then supports (deal analysis, admin, property management). Pulls from Google Calendar and suggests rearrangements.

## When to Use
- Sunday/Monday — plan the week
- Calendar feels chaotic — need structure
- Adding a new activity (marketing push, property visits) to the week
- Evaluating how you spend your time vs where revenue comes from

## Inputs
- **Current calendar** (via Google Calendar MCP)
- **Fixed commitments**: meetings, closings, appointments already scheduled
- **Priorities this week**: from mind/weekly-goals.md
- **Business model**: wholesale-heavy, flip-heavy, rental-focused, hybrid

## Process

### Step 1: Ideal RE Investor Time Blocks
| Block | Time | Activity | Revenue Impact |
|-------|------|----------|---------------|
| Money Time | 9-11 AM | Lead gen calls, follow-ups, seller appointments | HIGHEST |
| Deal Time | 11 AM-12 PM | Deal analysis, comps, offers, underwriting | HIGH |
| Close Time | 1-3 PM | Title company, contracts, dispo, buyer calls | HIGH |
| Build Time | 3-4 PM | Marketing, content, systems, team training | MEDIUM |
| Admin Time | 4-5 PM | Email, CRM updates, bookkeeping, planning | LOW |

### Step 2: Analyze Current Calendar
```
CURRENT WEEK BREAKDOWN:
  Revenue-generating activities:  [X] hrs ([X]%)
  Deal management:                [X] hrs ([X]%)
  Admin/overhead:                 [X] hrs ([X]%)
  Meetings (non-deal):            [X] hrs ([X]%)
  Free/unscheduled:               [X] hrs ([X]%)

TARGET: 60%+ revenue-generating, <20% admin
```

### Step 3: Optimization Recommendations
- Move non-urgent meetings to afternoon
- Batch admin tasks into one block
- Protect morning for outbound calls
- Batch property visits (same area, same day)
- Use Calendly to control when others book you

## Output Format
```
CALENDAR OPTIMIZATION — Week of [Date]
══════════════════════════════════════
Current: [X]% revenue time | [X]% admin
Target:  60%+ revenue time | <20% admin

RECOMMENDED CHANGES:
1. [Move X to Y]
2. [Block Z time for calls]
3. [Batch admin to Friday PM]

OPTIMIZED WEEK:
[Mon-Fri time block schedule]
```
