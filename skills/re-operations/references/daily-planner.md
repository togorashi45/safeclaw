# Daily Planner

## Overview
Plan your day using the Eisenhower matrix (urgent/important) combined with time-blocking. Pulls today's commitments, prioritizes tasks by revenue impact, and creates an hour-by-hour plan that protects your highest-value activities.

## When to Use
- Start of day — after daily briefing
- Midday reset — reprioritize after morning changes
- Planning tomorrow before end of day

## Inputs
- **Today's calendar** (from Google Calendar)
- **Task list**: from daily briefing, ClickUp, or manual
- **mind/weekly-goals.md** priorities
- **Energy level**: morning person? afternoon peak?

## Process

### Step 1: Eisenhower Matrix
| | URGENT | NOT URGENT |
|---|--------|-----------|
| **IMPORTANT** | DO FIRST: Deal deadlines, hot lead callbacks, closing tasks | SCHEDULE: Lead gen, marketing, systems building |
| **NOT IMPORTANT** | DELEGATE: Routine emails, data entry, scheduling | ELIMINATE: Social media browsing, unnecessary meetings |

### Step 2: Today's Task List (Prioritized)
| # | Task | Quadrant | Est Time | Revenue Impact |
|---|------|----------|----------|---------------|
| 1 | [Task] | DO FIRST | [X] min | $[X] |
| 2 | [Task] | DO FIRST | [X] min | $[X] |
| 3 | [Task] | SCHEDULE | [X] min | — |

### Step 3: Time-Blocked Plan
```
TODAY'S PLAN — [Date]
═════════════════════
8:00  — Review daily briefing, plan day (15 min)
8:15  — [DO FIRST task 1]
9:00  — [Money Time — outbound calls / follow-ups]
10:00 — [Money Time continued]
11:00 — [Deal analysis / comps / offers]
12:00 — Lunch
1:00  — [Scheduled meeting / appointment]
2:00  — [Close Time — contracts, dispo, title]
3:00  — [Build Time — marketing, systems]
4:00  — [Admin — email, CRM, bookkeeping]
4:45  — Plan tomorrow, update mind/ files
5:00  — Done
```

## Output Format
```
DAILY PLAN — [Date]
═══════════════════
Top 3 Priorities:
1. [Must complete today]
2. [Must complete today]
3. [Should complete today]

[Hour-by-hour schedule]

DELEGATE TODAY:
- [Task] → [Who]

ELIMINATE:
- [Task that doesn't need to happen]
```

## Example Prompts
- "Plan my day — I have a seller appointment at 2pm and need to make 20 cold calls."
- "Reprioritize my afternoon — a hot deal just came in."
- "What should I focus on today based on my weekly goals?"
