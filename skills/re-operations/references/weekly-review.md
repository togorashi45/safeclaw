# Weekly Review

## Overview
Structured end-of-week retrospective for your RE investment business. Reviews what happened across deals, marketing, finances, and operations. Compares against weekly goals, identifies wins and lessons, and sets up next week's priorities. Updates mind/weekly-goals.md.

## When to Use
- Friday afternoon or Sunday evening
- Before setting next week's goals
- Monthly — can aggregate 4 weekly reviews

## Inputs
- **mind/weekly-goals.md** — this week's targets
- **mind/active-deals.md** — deal pipeline changes
- **Deal activity** this week (new leads, offers, contracts, closings)
- **Financial data** — money in, money out
- **Marketing metrics** — leads, spend, results

## Process

### Step 1: Goal Review
```
THIS WEEK'S GOALS:
| Goal | Target | Actual | Hit? |
|------|--------|--------|------|
| [Priority 1] | [X] | [X] | Yes/No |
| [Priority 2] | [X] | [X] | Yes/No |
| [Priority 3] | [X] | [X] | Yes/No |

SCORE: [X] of [X] goals hit
```

### Step 2: Deal Pipeline Movement
```
DEALS THIS WEEK:
  New leads:          [X]
  Appointments set:   [X]
  Offers made:        [X]
  Contracts signed:   [X]
  Deals closed:       [X]
  Deals lost/dead:    [X]

PIPELINE CHANGES:
  Moved forward:   [X] deals
  Stalled:         [X] deals
  New to pipeline: [X] deals
  Total active:    [X] deals ($[X] projected revenue)
```

### Step 3: Financial Summary
```
MONEY THIS WEEK:
  Revenue received:      $[X]
  Expenses paid:         $[X]
  Net cash flow:         $[X]
  MTD Revenue:           $[X] of $[X] target
  On pace for month?     Yes/No
```

### Step 4: Marketing Performance
```
MARKETING THIS WEEK:
  Total spend:     $[X]
  Leads generated: [X]
  Cost per lead:   $[X]
  Best channel:    [Channel] — [X] leads at $[X] CPL
  Worst channel:   [Channel] — [X] leads at $[X] CPL
```

### Step 5: Wins and Lessons
```
WINS:
+ [What went well — be specific]
+ [Another win]

LESSONS:
- [What didn't work and why]
- [What to do differently]

BOTTLENECKS:
- [What's slowing things down]
```

### Step 6: Next Week Setup
```
NEXT WEEK'S PRIORITIES:
1. [Top priority for next week]
2. [Second priority]
3. [Third priority]

FOLLOW-UPS CARRYING OVER:
[Any unfinished follow-ups]
```

Update mind/weekly-goals.md with next week's priorities.

## Output Format
```
WEEKLY REVIEW — Week of [Date]
══════════════════════════════
GOALS: [X/X] hit
DEALS: [X] closed | [X] new to pipeline | [X] active
REVENUE: $[X] this week | $[X] MTD
MARKETING: $[X] spent → [X] leads ($[X] CPL)

WINS: [Top win]
LESSON: [Top lesson]

NEXT WEEK'S TOP 3:
1. [Priority]
2. [Priority]
3. [Priority]
```
